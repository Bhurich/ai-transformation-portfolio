# NPS City Godot Learning Simulation

## One-Line Pitch

Godot-based company learning simulation prototype that uses game mechanics to help employees explore company knowledge interactively.

## Business Problem

Company learning can become passive when it relies only on documents, slides, or one-way training. Interactive simulations can make learning more memorable and participatory.

## What I Built

- Godot 4 prototype
- Grid-based placement logic
- Company-related building/assets structure
- Save/load logic
- Interactive controls
- Foundation for gamified learning experience

## My Role

Game concept, prototype direction, AI-assisted development, interaction logic, learning experience design, and documentation.

## What This Proves

- I can use gamification beyond simple points and badges.
- I can prototype learning systems with game engines.
- I can turn company knowledge into interactive experience design.

## Relevance To AI Transformation

Capability building is part of transformation. This project shows how learning can become practical, interactive, and easier to adopt.
