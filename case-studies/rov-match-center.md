# NPS ROV 2026 Match Center

## One-Line Pitch

Tournament operations web app for schedules, teams, playoff brackets, live scoring, livestream links, roster views, and admin controls.

## Business Problem

Internal competitions and events become difficult to manage when schedules, scores, teams, livestream links, and admin updates are separated across many channels.

## What I Built

- Public dashboard
- Schedule and scoreboard
- Playoff bracket public view
- Live match page with Microsoft Teams stream link
- Team roster views
- Livestream link page
- Admin login
- Team management
- Match management
- Card draw system
- Live score control
- CSV export and pair list copy

## My Role

System design, event operations workflow, dashboard structure, admin flow, live update concept, and prototype build.

## What This Proves

- I can build operational systems for fast-moving internal events.
- I understand the need for public views and admin control.
- I can reduce manual coordination through structured workflows.
- I can design live-event pages that combine match context, stream access, teams, dates, status, and public visibility.

## Relevance To AI Transformation

Transformation work is about operating smarter. This project demonstrates my ability to map event complexity into a clear digital operating system.
